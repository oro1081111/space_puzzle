# 尾盤重複爭奪規則

規則版本：`exclusive-reach-endgame-cycle-v3`。ATLAS-R 名稱與權重仍為 v1.1；這次更新的是所有策略、人機與純 AI 模式共用的結束規則，ATLAS 搜尋分支也同步判斷新的終局。

只有剩 2～4 格空白時記錄每次有效行動結算後的所有棋子位置、排序後的暫時禁止格與本次是否搶格。棋盤領地只能增加、不能覆寫；每次領地增加即清空紀錄，因此同一段紀錄中的棋盤完全相同。非法點擊、模型失敗、暫停不記錄，重開清空。

保存最近 96 次紀錄，檢查長度 1～32 的完整循環。最後三個連續循環的每個狀態與事件須完全相同，且循環含搶格才結束。不是單一位置出現三次，也不是碰撞總共三次；中途離開循環不會誤算成連續重演。只是沒有得分的普通走位不適用。

結束原因顯示「尾盤重複爭奪：相同搶格循環連續重演 3 次」。剩餘空白不計分，比較已持有領地，只有同分才平手。這是遊戲的重複局面裁定，不是沒有其他可行策略的數學證明。超過四格、超過 32 步週期或不規則僵持仍沿用無進展安全上限；最後一格同時搶格依原規則立即結束。
