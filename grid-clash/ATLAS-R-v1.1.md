# ATLAS-R v1.1：循環脫困與對局結束防護

模型權重、ONNX 檔案不變；這是網頁控制器與遊戲規則修正，並非新訓練。原 `training/search.py` 保留 v1.0 無記憶搜尋供歷史比較；v1.1 的完整有記憶控制器以 `grid-clash/index.html` 為準，`training/oracle.cjs` 可直接呼叫它。Python 模擬器已同步新增結束規則，規則版本 `exclusive-reach-stalemate-v2`。

## 為何不是單純加隨機動作或提早判和

一回合搜尋看不出先後退再繞路的價值。每步任意換路或加小幅懲罰不保證離開循環，因此保留原搜尋，只有偵測到停滯才啟動持續的尋路模式。一般重複走位不等於規則上無路可走，不能立即結束。

## 脫困

- 自己至少 4 回合沒有增加領地，且目前位置在近期成功移動記錄出現至少 3 次；或自己連續 2×邊長回合未增加領地，啟動脫困。
- 用現有 BFS 找可達空白格，沿自己的領地前往；保留同一目標直到取得領地或該目標不可達，避免下一步又被原本搜尋拉回。
- 尊重暫時禁止格；沒有可達目標時原地等候解除。碰撞後改選其他目標（若有），雙方用相反方向排序同距離目標，減少鏡像搶格。
- 一旦自己增加領地，清除脫困記錄，回到原本搜尋。這不是為所有局面提供進度證明，仍有安全上限。

## 結束及例外

| 情況 | 處理 |
|---|---|
| 棋盤填滿 | 正常結束 |
| 仍有空白，但所有人都無法再到達 | 結束，空白不計分 |
| 只剩一格空白，多人同時搶該格 | 整回合不移動、不加分，立即結束；依現有分數決定勝負，分數相同才平手 |
| 還有多格空白的一般搶格 | 保留原取消回合與暫時禁止規則，不立即結束 |
| 長時間無人增加領地，含反覆搶格／等待 | 連續 2×棋盤格數次有效結算嘗試後結束：15×15 為 450，30×30 為 1800；以現有分數結算 |
| 在安全上限那次取得新領地 | 計數歸零，不判僵持 |
| 非法點擊、暫停、模型載入失敗 | 不計入有效行動，不以此推進或結束 |
| 玩家完全無合法方向 | 點擊可原地等待，其他 AI 繼續；不再要求一定有暫時禁止格 |
| 原回合上限 | 保留超過 8×棋盤格數的保底上限，畫面顯示原因 |

無進展上限是公開的防空轉規則，不是「數學上已無任何可得分走法」的宣稱。暫時禁止格仍不影響永久圈地判斷；其他玩家的既有領地不被覆蓋。

## 驗證結果

`python -m training.check_atlas11` 使用實際網頁控制器與原 ONNX 權重，每一步與 Python 規則比對。每尺寸 6 場（標準開局＋5 個四步隨機前綴）：

| 棋盤 | 填滿結束 | 結束回合 | 最長連續無進展 | 觸發安全上限 |
|---|---|---|---|---|
| 15×15 | 6/6 | 207、95、153、51、177、221 | 16 次 | 0 |
| 30×30 | 6/6 | 251、241、938、536、253、718 | 50 次 | 0 |

Edge 真實 WASM 完整自我對弈也確認標準 15×15 在 207 回合、30×30 在 251 回合填滿。

另以 `node tests/collision.test.cjs` 驗證最後一格搶格、普通搶格不誤結束、取消回合達安全上限、非法點擊不計次、得地重置上限、永久受困玩家等待；`node tests/atlas.test.cjs` 保留 160 個無歷史局面的 v1.0 搜尋相容性測試；`node tests/browser.test.cjs` 包含完整自我對弈、暫停／重開丟棄舊推論與模型失敗測試。

12 場是回歸測試，不是全面棋力評估。v1.0 歷史勝率不能直接當作 v1.1 勝率；30×30 仍標為實驗性，多人 ATLAS 仍不開放。
